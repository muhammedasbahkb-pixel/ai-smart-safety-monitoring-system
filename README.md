## 📌 Overview

This project is an AI-powered industrial safety monitoring system that combines machine learning, IoT sensors, and real-time prediction to detect hazardous gas leaks and water-related risks.

The system continuously monitors environmental conditions using sensors connected to an ESP8266 and classifies situations into different safety levels using a trained machine learning model.

---

## 🚀 Features

- Real-time gas leak detection
- Water hazard monitoring
- Machine learning prediction
- Confidence score generation
- Flask API integration
- ESP8266 sensor communication
- Live safety monitoring

## 🧠 Hazard Classes

| Class | Meaning |
|---------|---------|
| Normal | Safe Conditions |
| Gas Leak | High Gas Level |
| Water High | Water Hazard Detected |
| Danger | Gas Leak + Water Hazard |
